# 정렬 알고리즘 비교

삽입 정렬, 퀵 정렬, 힙 정렬의 실행 시간과 비교·이동 횟수를 비교한다. 퀵 정렬에서는 마지막 원소를 피벗으로 사용하고, 힙 정렬에서는 최대 힙을 사용한다.

## 실행 방법

저장소의 맨 위에서 다음 명령을 실행한다.

```sh
make test
make run
make csv
```

`make test`는 각 정렬 결과가 오름차순인지 확인한다. `make run`은 표를 출력하고, `make csv`는 보고서용 `results.csv`를 만든다.

## 실험 조건

- 입력 크기: 1,000 / 2,000 / 4,000 / 8,000개
- 입력 형태: 무작위 / 정렬됨 / 역순 / 중복 많음
- 각 조건에서 세 번 실행한 평균 시간(ms)을 기록
- 세 알고리즘에 같은 입력 배열 사용
- 비교·이동 횟수는 마지막 반복의 측정값

`stable`은 해당 입력에서 같은 키의 순서가 유지되었는지 나타낸다. 중복 키가 없는 입력에서는 안정 정렬 여부를 판단할 수 없다. 퀵 정렬은 마지막 원소를 피벗으로 택하므로 정렬된 입력에서 성능이 나빠질 수 있다.
